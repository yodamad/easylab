Shared by the Provider Credentials and DNS pages. Rendered with the page's credentialStorageView: {{template "credential-storage" .Storage}} Every form answers with HX-Refresh, so the whole page reflects the new state. */}} {{define "credential-storage"}}

Credential storage

{{if eq .State "disabled"}}

Credentials are kept in memory only and are cleared when EasyLab restarts.

No data directory is configured, so nothing can be saved.

{{else if eq .State "uninitialized"}}

Credentials are kept in memory only and are cleared when EasyLab restarts.

Set a passphrase to save them encrypted. The passphrase is never written to disk: after a restart you enter it once here instead of typing every credential again.

At least {{.MinPassphraseLength}} characters. It cannot be recovered if lost.
{{else if eq .State "locked"}}

Saved credentials are locked. Enter the passphrase to use them again.

Until then, saved cloud credentials and DNS profiles are unavailable. Running labs are not affected.

{{else if eq .State "unlocked"}} {{if eq .KeySource "env"}}

Credentials are saved encrypted under LAB_DATA_ENCRYPTION_KEY.

They are available again automatically after a restart, as long as the same key is set.

{{else}}

Credentials are saved encrypted under your passphrase.

After a restart, enter the passphrase once here to use them again.

Change passphrase or lock
At least {{.MinPassphraseLength}} characters.
Saved DNS profiles become unavailable until you unlock. Cloud credentials already in use stay in memory until EasyLab restarts.
{{end}} {{else}}

Saved credentials cannot be read. They were saved under a LAB_DATA_ENCRYPTION_KEY that is no longer set, or the file is damaged.

Restart EasyLab with the original key, or reset credential storage and enter the credentials again.

{{end}} {{if or (eq .State "locked") (eq .State "unlocked") (eq .State "unreadable")}}
Reset credential storage
Deletes every saved cloud credential and DNS profile. This cannot be undone. Existing labs keep the DNS credentials they were created with.
{{end}}
{{end}}
