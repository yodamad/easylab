In-lab student portals

A lab can run its own student portal inside its cluster. These settings are what every portal gets from this instance. Leave a field empty to use its default. Each portal's password is its own and is set on its lab's page — so a password handed to one lab's students opens that lab and no other.

{{else if not .EffectivePublicURL}}

{{else}}

Portals run {{.EffectiveImage}} and send students to {{.EffectivePublicURL}} for Microsoft, GitHub and GitLab sign-in.

This instance's own student area

This instance serves a student area of its own, and it has its own password — separate from every in-lab portal's. It lists every lab, so it is the one password that reaches all of them: run EasyLab with -mode=admin if you want each lab reachable only through its own portal.
